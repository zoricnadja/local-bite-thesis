## Генерисање PDF-а

Инсталирати [Typst CLI](https://github.com/typst/typst#installation) и фонтове Liberation Serif, Liberation Sans и Consolas. Актуелни PDF је генерисан верзијом Typst 0.15.1.

Из корена овог репозиторијума покренути:

```powershell
typst compile zavrsni-rad.typ zavrsni-rad.pdf
```

За аутоматско генерисање после сваке сачуване измене:

```powershell
typst watch zavrsni-rad.typ zavrsni-rad.pdf
```

Прво покретање захтева интернет за преузимање верзионисаних Typst пакета `hydra:0.6.2` и `citegeist:0.2.0`. Наредна покретања користе локални кеш. PDF се чува у репозиторијуму како би био доступан за читање без инсталације Typst-а.

## Организација извора

| Путања | Намена |
| --- | --- |
| `zavrsni-rad.typ` | Главни документ, укључивање поглавља, спискови и литература |
| `metadata.typ` | Наслов, аутор, ментор, апстракти и подаци за обрасце |
| `poglavlja/01-*.typ` — `12-*.typ` | Основна поглавља рада |
| `poglavlja/dodatak-*.typ` | Додаци и списак скраћеница |
| `biografija.typ` | Биографија аутора |
| `literatura.bib` | Активна BibTeX литература; цитирање преко `@кључ` или `#cite(<кључ>)` |
| `slike/v4/` | Слике које се користе у раду |
| `formulari/`, `logo/` | Ресурси изворног шаблона |

Поглавља се уређују у својим `.typ` датотекама. Насловна страна и обрасци користе податке из `metadata.typ`. Датум одбране и непопуњени подаци о комисији уносе се по потврди ментора; пре предаје треба потврдити и текст задатка. Спискови слика и табела, референце и литература генеришу се аутоматски.

## Рад на изменама

Овај fork је репозиторијум за даљи рад на тексту дипломског. После измена генерисати и прегледати PDF, па сачувати повезане изворе и PDF у истом commit-у и послати их у овај fork. Пример за једно измењено поглавље:

```powershell
git diff
typst compile zavrsni-rad.typ zavrsni-rad.pdf
git add poglavlja/01-uvod.typ zavrsni-rad.pdf
git diff --cached --stat
git commit -m "Дорада увода"
git push origin main
```

У `git add` навести стварно измењене датотеке. У репозиторијум се не додају извршни фајлови алата, локални рендери, резервне копије и старе Office верзије рада.
